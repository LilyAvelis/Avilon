# GUI

[Темы МИРЫ](mira/README.md) — десять запускаемых desktop-шаблонов на Rust/egui,
базовые компоновки и проверка на окне настроек без галереи.

[avilon-egui](../crates/avilon-egui/README.md) содержит готовые компоненты GUI:
темы, строки настроек, вкладки, клавиатурные подсказки, палитры и материалы.
[Гайд по Design SDK](../docs/design-sdk.md) описывает подключение и оптические
эффекты. Самостоятельные эксперименты с эффектами могут жить рядом с темами
в разделе GUI.
