# Лаборатория воды · пятый опыт HDRP

Проект для сборки единой [Лаборатории воды](../unity-water-lab/README.md) МИРЫ. В Windows открыть **Кинетика → Проекты Unity → Лаборатория воды**. Четыре опыта используют Built-in. Панель **Новая вода · HDRP** и клавиша **5** включают **Unity HDRP Water 17.3.0**. Сцена и камера остаются общими. Водяной решатель сохраняет активные волны при смене рендера. Проект работает в Unity 6000.3.29f1 и собирается с Direct3D 12.

## Что сравнивать

- В пятом опыте HDRP рассчитывает преломление, отражения и подвижные световые узоры на дне. Плитка показывает, как рябь нарушает прямые линии. Spectre позволяет посмотреть, как оптика ведёт себя возле уступов и ложбин.
- Ветер меняет нативную симуляцию волн и мелкой ряби. ЛКМ, падающий шарик, дождь и град продолжают возбуждать одно поле ударов МИРЫ.
- Water Decal передаёт подписанную высоту в HDRP без чтения через CPU. Область закреплена на уровне Y=0 и покрывает 236 × 236 м. Максимальное разрешение деформации HDRP здесь 2048². Ползунок «Поле ударов» меняет сетку решателя. Более высокая ступень может сохранить мелкие детали расчёта до передачи в HDRP.
- HDRP рассчитывает световые узоры под водой при ветре. Физические осадки идут через общий GPU-решатель. Размер следа мелкой капли учитывает шаг фильтра деформации HDRP, иначе впадина и гребень гасят друг друга. Вариант визуального дождя «Кольца» доступен в первых четырёх опытах.
- Декаль выключается при пустом поле и получает новые данные после шага решателя. Запрос высоты из HDRP включается при движении шарика в ветреную погоду. В пятом опыте интервал VSync выбирается с учётом целевого бюджета 90 FPS, если синхронизация включена.

## Сборка

Из корня Avilon выполнить `./experiments/unity-water-hdrp/publish.ps1`. Команда обновляет `Assets/Shared` из исходного проекта, подготавливает сцену и собирает Windows Player. Затем она проверяет переходы между рендерами в редакторе и запуск Player. Путь в `target/water-lab-current.txt` меняется только после успешного прогона. Каждый выпуск живёт в отдельной папке, поэтому предыдущий Player можно оставить открытым.

Для ручной отладки остаются **Mira → Prepare HDRP Water Laboratory** и **Mira → Build HDRP Water Laboratory**. После изменений общих исходников сначала выполнить `sync-shared.ps1`. Сборщик сверяет общие ассеты и отпечаток подготовленных входов. Ручная сборка пишет в `target/unity-water-lab-combined` или каталог из `MIRA_WATER_HDRP_OUTPUT`.

Приёмка в Play Mode запускается командой `HdrpWaterLabAcceptance.Start` с `MIRA_WATER_HDRP_CAPTURE`, указывающей папку кадров, и графическим адаптером. Она проходит 03 → 05 → 04 → 05, проверяет камеру и координаты удара, читает деформацию при дожде и сильном граде в двух областях, затем сравнивает время рендера с синхронизацией GPU для камеры 3840 × 2160. Этот замер характеризует отдельный кадр в редакторе и не включает текущий шаг физики дождя. Единый проект использует линейное цветовое пространство.
