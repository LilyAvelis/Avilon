# Продолжение луча Spectre

Исходный луч лаборатории с seed 23 продолжен до 50 км. Все 26 переходов из записи Unity воспроизвелись с максимальной разницей 1,42 × 10⁻¹² м. При возобновлении в четырёх участках, в том числе после остановок ровно на двух швах, получились те же 8 311 событий. Проверка использует Python 3.10+ и стандартную библиотеку.

```powershell
python -B experiments/spectre-continuation/check.py
```

Файл `water-seed23.json` содержит 26 абсолютных расстояний из исходного прогона Unity. Для сверки с собственным экспортом передай `--recording target/spectre-ray/crossings.csv`. Флаг `--full` дополнительно обходит все грани и швы в суперплитке из 272 791 плитки.

## Как сохранить адрес

У исходной суперплитки Δ фиксируются положение, ориентация и версия правил. Для расширения берётся предок Δ на два поколения выше. В его четвёртом слоте при нумерации от нуля находится Σ, а в слоте 1 этой Σ — прежняя Δ. Обратное преобразование совмещает прежнюю Δ с её точным прежним положением. Остальные дочерние плитки достраивают окрестность. Выбор этой цепочки определяет **одно** допустимое продолжение исходного фрагмента. Другой выбор совместимого предка может дать другой рисунок за пределами исходного фрагмента.

Вершина представляется четырьмя целыми числами — коэффициентами в базисе 1, ζ, ζ², ζ³, где ζ = exp(iπ/6) и ζ⁴ = ζ² − 1. Повороты на 30°, сопряжения и переносы вычисляются точно. В выбранной системе отсчёта плитка адресуется исходной вершиной и поворотом, общий криволинейный шов — двумя концами в каноническом порядке. Порядок обхода и число построенных предков на адрес не влияют. Масштаб в метрах и смещение для камеры хранятся отдельно. Для той же системы координат существует независимое описание. [Simon Tatham, Exact plane coordinates](https://www.chiark.greenend.org.uk/~sgtatham/quasiblog/aperiodic-spectre/#exact-coords)

## Что проверено

| 1 500 м | 233 | 26 | 578 |

В независимой проверке вложенности все 4 401 плитка меньшего участка сохранили точные адреса в большем из 272 791 плитки. Все прежние внутренние швы сохранили обе стороны. Для этого испытания нижняя оценка расстояния от якоря до границы выросла с 26,416 до 199,327 длин ребра. Оценка учитывает максимальное отклонение кубической границы от хорды.

У 8 310 интервалов луча seed 23 проверены все возможные длины периода от 1 до 4 155. Ни одна не воспроизвела всю запись с допуском 0,01 ребра. Такой же поиск по первым десятичным цифрам длин, выраженных в рёбрах, также дал пустой результат. Цифра 4 встретилась 1 422 раза, цифра 9 — 265.

## Границы вывода

Доказана апериодичность двумерного замощения. Одномерная запись теряет сведения о том, что находится по сторонам луча. Геометрическая апериодичность сама по себе не устанавливает апериодичность каждой прямой секущей, а округление теряет ещё больше информации. Конечный эксперимент проверяет заявленные длины, направления и лаги. [Smith, Myers, Kaplan, Goodman-Strauss, A chiral aperiodic monotile](https://cs.uwaterloo.ca/~csk/spectre/)

Адреса швов целочисленные. Параметры пересечений вычисляются в double. Текущий научный тест выбирает обычные поперечные попадания. Для движка касания без смены владельца и проходы точно через общую вершину требуют отдельного правила событий. На далёких участках пригодится локальная система отсчёта с точным переносом. Положительная нижняя оценка покрытия проверена для построенных предков. Исчерпание всей плоскости этой конкретной бесконечной цепочкой остаётся отдельным утверждением.
