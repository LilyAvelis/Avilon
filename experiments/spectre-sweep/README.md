# Луч Spectre 360°

Открой `target/spectre-sweep/index.html`. Луч начинает вращаться автоматически. Пауза, ползунок и щелчок по полю позволяют выбрать направление. Кнопки «До» и «После» показывают один и тот же порядковый номер с двух сторон от касания. Если в системе включено уменьшение движения, страница открывается на паузе.

В МИРЕ опыт доступен в разделе **Анимация → HTML → Луч Spectre 360°**. Атлас показывает превью и открывает встроенную в сборку автономную страницу в браузере. При обновлении опыта положи новый `index.html` и JPEG-превью в [ассеты атласа](../../gui/mira/showcase/assets/animation) под именами `spectre-360.html` и `spectre-360.jpg`.

## Что измеряется

Источник лежит внутри опорной плитки в точке (1,41; 0,83) в системе протоплитки. Луч заканчивается на окружности радиуса 12 длин ребра. Начало №1 совпадает с источником, конец — с первым пересекаемым швом. Отрезок №2 лежит между первым и вторым швами. Последний неполный остаток до окружности исключён. Полярный след даёт длину выбранного отрезка по 1 440 направлениям с шагом 0,25°. На графике соединены соседние измерения, у которых совпадают оба ограничивающих шва. Отдельные измерения показаны точками.

При 78° луч завершает восемь отрезков. По мере поворота третье и четвёртое пересечения одного шва №229 сближаются. В 78,11561251° луч касается его, а к 78,25° остаются шесть пересечений. Теперь №4 обозначает другой участок. Его длина меняется с 0,134577 до 4,309064, а первый выход в этой паре углов смещается с 1,528324 до 1,530725.

Существует и другой случай. В 354,98425008° исчезает пара пересечений ближайшего к источнику шва №221. Следующим видимым оказывается шов №248. Между 354,75° и 355° первый отрезок вырастает с 1,145784 до 1,958011. Поэтому у вогнутой плитки полярный след первого выхода описывает доступную из источника часть границы и тоже может иметь разрывы.

Эксперимент фиксирует один фрагмент, один источник и конечный радиус. Выбор другого источника или радиуса меняет картину. Сетка углов проходит через обычные поперечные пересечения. Критические углы двух примеров найдены дополнительно из условия параллельности луча и производной кубической кривой. Точки в самих касаниях в таблицу дискретного оборота не входят.

## Геометрия и проверка

Правила подстановки и точные адреса вершин берутся из соседнего `spectre-continuation/check.py`. Видимая область включает 197 полных плиток четырёх поколений от корня. Физический шов с длиной хорды 1 задаётся в локальных координатах кривой `(t, 0.96 t(1−t)(1−2t))`. Это наш выбор контура в семействе Spectre. Он сохраняет форму шва при повороте на 180° и обмене концами. Правила подстановки опубликованы авторами. Копия лицензии BSD 3-Clause включена в HTML. [Smith, Myers, Kaplan и Goodman-Strauss, *A chiral aperiodic monotile*](https://cs.uwaterloo.ca/~csk/spectre/)

Главный расчёт пересекает луч с кубическими швами. Контроль пересекает луч с 256 хордами на каждый шов для 131 направления. Все 882 пересечения имеют тот же идентификатор и порядок. Наибольшее расхождение расстояний составляет 0,00004111 длины ребра. Положение середины каждого из 882 отрезков независимо сверено с контуром его плитки. За полный оборот получены 9 702 отрезка, от 3 до 17 в одном направлении.

Центры масс относятся к **целым криволинейным плиткам** при равномерной поверхностной плотности. Интегралы Грина по кубическим рёбрам вычислены пяточечной квадратурой Гаусса, точной для возникающих многочленов до степени 8 с учётом машинного округления. Проверка площади и центра использует независимые многоугольные моменты при 1 024 хордах на ребро. Площадь протоплитки равна 8,196152423, её центр равен (1,383974596; 1,066987298). Координаты центров в CSV отсчитываются от источника луча. Ось Y направлена вверх.

## Сборка и файлы

Из корня Mira, Python 3.10+ со стандартной библиотекой.

```powershell
python -B experiments/spectre-sweep/build.py
```

В `target/spectre-sweep` появятся автономный `index.html`, все интервалы в `segments.csv`, центры масс и адреса в `centroids.csv`, результаты проверок в `verification.json`. Нумерация плиток и швов локальна для этой выгрузки. Адрес плитки задают четыре целых коэффициента её исходной вершины и угол поворота в единицах 30°.

Проверка интерфейса запускает установленный Edge в фоновом режиме, отключает сеть, проверяет управление и численное совпадение обоих экспортов, сохраняет `preview.png`. Для другого Chromium передай `--browser <путь>`.

```powershell
uv run --no-project --with playwright python -B experiments/spectre-sweep/verify_browser.py
```
